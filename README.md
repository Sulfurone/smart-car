## 获取资料

较大的压缩包、PCB 库和文档使用 Git LFS 保存。安装 Git LFS 后克隆仓库，即可获得文件内容：

```sh
git lfs install
git clone https://github.com/Sulfurone/smart-car.git
```

如果已克隆仓库但大文件只有指针文本，可在仓库目录执行 `git lfs pull`。

## 使用工程

- TC264 工程以 `.project`、`.cproject` 为入口；Keil 示例以 `.uvproj` 为入口。
- Altium 工程以 `.PrjPcb` 为入口，独立设计可直接打开 `.SchDoc`、`.PcbDoc`；工程配套库保存在对应目录。
- 原有工程内部相对目录结构保留，未合并同名工程或不同版本。
- 旧工具链如果不支持空格或中文路径，可将需要编译的单个工程复制到较短的英文路径后打开。
- 文件名中的“未验证”“未成功验证”等标注保留，使用前请确认对应设计状态。
- 同时包含硬件、软件和说明的综合资料包保持原有压缩形式。
